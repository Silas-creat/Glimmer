## 4. 逐项修复结果（R1–R6）

### R1 草稿发送前身份绑定（P1）

- 根因：`prepareDraft` 仅校验 `panelEpoch/draftEpoch`，未绑定账号与身份代次；confirm/cancel 同样缺少账号归属。
- 改动：新增 `state.identityEpoch`、`state.draftMaterial`、`state.draftOwner` 与 `resolveIdentity` 三态复核；prepare/confirm/cancel 在请求前复核，响应落地前用 `isDraftResponseCurrent` 复查；材料在 `renderDraftSelection` 时绑定账号与代次。
- 决策：同账号 token 刷新不视为身份变化，`/auth/me` 确认同账号后继续；正常本地一致路径不发 `/auth/me`。
- 对应用例：EDGE-R1-01、R1-02、R1-03、R1-04。
- 结果：修复后 4 条全绿（单文件回归）。
- 状态：`已修复-待人工复核`。

### R2 清除中的记忆读取失效（P1）

- 根因：清除成功只清 `memorySnapshot`，未使在途读取失效；面板影响域只按 `panelEpoch` 判断。
- 改动：新增 `state.clearEpoch`、`state.readSeq`、`state.panelKind`、`createReadTicket`、`isReadValid`；历史与记忆读取均携带票据；清除成功推进 `clearEpoch/readSeq`，并按 `panelKind` 分派：`memory`/`history` 显示空态，`draft` 不动 DOM，`clear` 显示成功文案。
- 决策：清除成功时已打开的草稿面板保留可确认，不追加面板内提示。
- 对应用例：EDGE-R2-01、R2-02、R2-03；既有 P2-01、P2-02、P2-03。
- 结果：修复后 3 条全绿，既有 P2 系列全绿。
- 状态：`已修复-待人工复核`。

### R3 旧账号清除响应隔离（P2）

- 根因：清除成功回调无条件 `replaceSession` 并清空当前页面，跨账号迟到响应会清掉新账号内容。
- 改动：新增 `state.clearSeq` 与 `ClearOp`；`judgeClearResponse` 按“操作序号 → 账号 → 身份代次 → 面板”四级裁决；跨账号直接丢弃；同账号但面板已关闭时只清上下文、不写面板。
- 决策：同账号关闭面板后仍清理旧上下文，面板代次不作为跳过清理的唯一条件。
- 对应用例：EDGE-R3-01、R3-02、R3-03；既有 P1-05、P1-06、P2-01、P2-03。
- 结果：修复后 3 条全绿，既有用例全绿。
- 状态：`已修复-待人工复核`。

### R4 发送锁归属（P2）

- 根因：`sending` 是全局布尔；旧请求 `finally` 无条件解锁，第三次点击可进入并渲染气泡但实际未发送。
- 改动：新增 `state.activeSend`、`state.sendSeq`、`beginSend`（任何 `await` 前同步占位）、`isSendCurrent`、`settleSend`（仅拥有者释放锁与按钮）；发送响应按“拥有者 + 会话 + 代次 + 账号”核对。
- 决策：发送入口同步占位，覆盖连续点击与身份复核窗口。
- 对应用例：EDGE-R4-01、R4-02、R4-03；既有 P1-04、P1-06、P1-07、P1-08。
- 结果：修复后 3 条全绿，既有用例全绿。
- 状态：`已修复-待人工复核`。

### R5 确认后的关怀可见性（P2）

- 根因：confirm 成功只调用 `showCare` 渲染背景关怀区，成功弹层内没有 care。
- 改动：`renderConfirmSuccess(data, care)` 在当前弹层内调用既有 `appendCareFull`（正文 + 渠道 + `tel:`），confirm 成功分支改为单一调用；幂等恢复成功复用同一分支。
- 决策：confirm 失败返回 care 时保持现状，不新增完整 `tel:` 展示。
- 对应用例：EDGE-R5-01、R5-02、R5-03；既有 B1、B4、normal confirm。
- 结果：修复后 3 条全绿，既有用例全绿。
- 状态：`已修复-待人工复核`。

### R6 停止生成的终态（P3）

- 根因：`draft:null + care` 只追加文字与关怀，生成按钮重新可用，可重复 prepare 并重复追加关怀。
- 改动：新增 `renderStopped` 与 `draftStatus='stopped'`；停止分支不再解锁“生成草稿”，面板提供“关闭”和“返回聊天”；网络失败不进入停止态。
- 决策：停止终态同时提供面板“关闭”和终态内“返回聊天”，不提供“重新生成”。
- 对应用例：EDGE-R6-01、R6-02、R6-03；既有 B4。
- 结果：修复后 3 条全绿，既有 B4 全绿。
- 状态：`已修复-待人工复核`。
