### 一键安装.bat 会做什么

| 步骤 | 说明 |
|---|---|
| 检查 Node | 需要 18 以上 |
| 检查 MySQL | 在跑就直接用；本机有就启动；**都没有会自动下载安装**（约 222MB，阿里云镜像，装到 D:\mysql） |
| 连不上已有 MySQL | 这台机器上如果装了别的 MySQL、而你不知道 root 密码，脚本会让你二选一：**1) 手动输密码；2) 另装一个独立实例**（端口 3307，密码脚本自己设，不碰你原有的）——不知道密码就**直接回车选 2** |
| 建数据库 | `peizhe` 库 + 23 张表。**已存在就跳过，不会删数据** |
| 灌演示数据 | 主账号 + 6 个演示用户、13 篇日记、4 个群、私信、祝福、漂流瓶、AI 对话 |
| 生成配置 | `后端源码/.env`，数据库密码随机生成 |
| 装依赖 | `npm install` |

> 只想检查不修改：`node setup/install.js --check`

### 一键启动.bat 会做什么

1. MySQL 没跑就拉起来
2. 后端没起就起（3000）
3. 起静态服务（端口被占用会自动往后找），把 `/api`、`/uploads` 转发给后端，然后开浏览器

## 三、最重要的一件事：`前端参考/api.js` 里有一层适配

页面里写的是 `api('/diary/public')`，但后端真实接口是 `/diary/feed?feed=all`。
**你不用改页面**，改的是 `api.js` 底部的 `translate()`：

```js
if (pathname === '/diary/public') {
  return { path: '/diary/feed?feed=all&size=' + (query.get('size') || 20), method: 'GET', kind: 'diaryList' };
}
```

返回值也会被 `shapeResult()` 转成页面要的字段（`text→content`、`img→cover`、`dateKey→day`、`isPublic→visibility`、`nick→author.nickname`）。

**以后加新功能**：后端已有对应接口，就在 `translate()` 里加一条映射；没有的话才需要动后端（那会影响接口文档里“92 个接口”这个数）。

## 六、几条产品规则（容易踩）

**私密日记对外是 404，不是 403** —— 别人的私密日记取详情/点赞/评论全部返回「内容不存在」。

**私信要先关注** —— 没关注对方时返回 403。

**一天只能写一篇日记** —— 按日期唯一，重复保存同一天是更新。

**群聊有内容审核** —— 发广告被拦（返回 `blocked: true`）；自伤倾向内容不拦截，但返回里带 `care` 热线列表。

**AI 统一走后端** —— `chat.html` 已移除浏览器端模型直连和内嵌 Key，改为调用后端 `/api/ai/chat`；Key 只放在 `后端源码/.env` 的 `DEEPSEEK_API_KEY` 里。
`.env` 没填 Key 时使用内置兜底回复，能跑通流程但不会真的理解，页面会明确标注当前是本地模式。

## 八、常见问题

**端口被占用**：不用管，脚本会自动往后找，窗口里会显示实际端口。

**登录进不去**：密码框必须填 `123456`（验证码），不是真的密码。

**8080 打开白屏**：看启动窗口报错；后端没起时页面会提示「后端没起来」。

**想完全重来**：删掉 `后端源码/.env` 重跑一键安装（数据库数据还在）。

**MySQL 装在哪**：默认 `D:\mysql`（没 D 盘就装到用户目录），可用环境变量 `MYSQL_DIR` 改。
