# 二十三稿 · 更新说明

> 这一版是在二十二稿基础上的一轮修 bug / 补体验。**接口没有变**（仍是 92 个），
> 数据库只多了一个 `messages.is_sys` 字段（加好友问候用，启动时会自动补）。

## 一、这一版修了什么

### 1. 聊天显示时间

群聊、私聊原来只有气泡，一条时间都没有。现在按微信的习惯：

- 两条消息间隔 **超过 5 分钟**，插一条居中的小灰字
- 同一天显示 `10:38`，昨天显示 `昨天 16:43`，更早显示 `11月2日 09:15`
- 进群时那一屏历史消息也有时间（原来只给新消息加，历史是一把塞进去的）

### 2. 新账号不再一进来就“十几条未读”

原来未读 = 「比我读到的 id 大的消息数」，新账号没有阅读记录，`last_read_id` 按 0 算，
于是四个群的历史消息全被算成未读（同龄群 12、拾趣 6、同省群 5、星迹 3）。

现在：

- 没进过某个群（没有成员记录）→ 该群未读算 0
- 第一次进群时，阅读位置设成「当前最新一条」，历史不进未读

### 3. 登录页去掉「先随便看看（不登录，演示用）」

这个入口早期演示用，正式版里没有任何实际作用（数据都要登录才能拿），
留着容易让人以为能绕过登录。已连同 `guest()` 一起删掉。

### 4. 浏览记录改网格

原来一条记录占一整行，现在手机 2 列、宽屏 3 列，卡片带日记封面 + 暗角 + 白字，
整块可点进详情。没有封面的日记用纯色底兜底。

### 5. 我的漂流瓶改信纸卡片

每条瓶子做成一张信纸卡片（用「微光同行」那 7 张信纸，按瓶子 id 固定），
文字垫一层半透明纸，压住花纹也看得清。

### 6. 发现页配图换成真实照片

之前演示日记用的是 `uploads/demo_*.svg` 那种柔和渐变块，容易被当成“图片没加载出来”。
现在改用 `assets/diary-month/01~12.jpg` 这套节气实拍图（和“写日记”页可选封面是同一套）。
用户自己写日记没选封面时，仍是纯色卡片兜底。

### 7. 漂流瓶详情去掉「送 ta 一句祝福」

捞到别人的瓶子只看内容，不再从这里发祝福。
（后端接口保留，将来要加回来很容易。）

## 二、更早那几轮已经修好的（这版都在）

- **加好友**：好友页「扫一扫」（可扫二维码，也能选图片识别）+「搜 ID 加好友」
  （ID / 昵称 / 二维码链接都认），已关注的标灰「已关注」，不会误取关
- **加好友问候**：关注成功后，双方私聊出现一条灰色系统提示「你们已经成为好友啦，去打个招呼吧」；
  取消关注自动清掉
- **头像进主页**：好友列表、群聊消息、私聊顶部，点头像都能进对方主页；
  好友列表点整行直接进私信（原来的「私信」按钮去掉了）
- **举报**：日记详情 / 他人主页右上角「⋯」、每条评论右侧「⋯」；记录在「设置 → 举报记录」
- **二维码**：设置页生成真二维码（服务端生成 SVG），别人扫码或粘链接都能加你
- **单点登录**：换设备登录把旧设备顶下线，被顶的那台 10 秒内自动回登录页
- **创建账号**：登录页「还没有账号？创建一个」，自填昵称；昵称重名会提示

## 三、安装相关的修复（这版都在）

| 问题 | 现在 |
|---|---|
| 项目路径带中文/空格时，建表报 `Failed to open file ... schema.sql` | 改成把 SQL 读进内存走 stdin，路径不再参与解析 |
| 另装独立 MySQL 实例起不来（和已有实例抢 33060 端口） | 给独立实例单独指定 X Plugin 端口，失败时打印 MySQL 错误日志 |
| 表结构升级（migrate）在 .env 生成之前跑，必然失败 | 挪到「写完 .env + 装完依赖」之后；`一键启动` 前也会先跑一次 |
| 登录报 `Unknown column 'users.session_version'`（500） | 后端启动时自动检查、缺字段直接补 |
| 好友列表里同一个人出现两次 | 接口 `DISTINCT` + 迁移补 `follows` 唯一索引 + 前端按 userId 去重 |
| 库里出现两个同昵称账号 | 新增 `node scripts/fix-duplicate-nick.js`（先预览，加 `--apply` 真改） |

## 四、怎么跑

```bat
:: 第一次：体检（不改任何东西）
node setup\install.js --check

:: 安装（建库、装依赖、灌演示数据）
node setup\install.js

:: 启动
node setup\start.js
```

浏览器打开 `http://localhost:8080`，登录 `13800138000` / 验证码 `123456`。

更详细的安装/排错见 [`前置安装指南.md`](../guides/前置安装指南.md)。
