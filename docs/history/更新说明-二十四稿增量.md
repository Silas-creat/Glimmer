## 一、修了什么

### 评论数 / 收藏数看不见

现象：评论区里能看见自己刚发的评论，但日记卡右侧那个「💬 评论」一直写着“评论”两个字，
发现页的卡片也只有点赞数，看不出这篇被评论了几条。

原因：后端一直在返回 `comments`（总条数），是前端没接。三处一起补上：

**1. 日记详情右侧操作栏** —— “评论”两个字换成真实条数

```
改前：  ♡ 0      ☆ 收藏     💬 评论      ✓ 已关注   ↗ 转发
改后：  ♡ 0      ☆ 收藏     💬 5         ✓ 已关注   ↗ 转发
```

**2. 发完评论/回复后，外面的数字跟着 +1**

原来发完只往评论区列表里塞一条，外面那个数字不动，看起来像“没生效”。
现在发完立刻更新（后端已经写库，这里只更新显示），回复同样处理。

**3. 发现页卡片底部** —— 点赞数旁边加上评论数

```
改前：  小光        11.04    ♡ 1
改后：  小光        💬 4  ♡ 1
```

**4. 收藏数（同一轮补的）**

收藏原来也只有“收藏”两个字。现在：

- 详情页操作栏 `☆` 下面是收藏条数，点一下收藏/取消会跟着 ±1
- 发现页卡片底部 `💬 评论  ☆ 收藏  ♡ 点赞` 三个数字并排
- 后端在日记查询里补了一个 `favorite_count`（实时数 favorites 表），序列化成 `saves`；
  没有加冗余字段，所以不存在"计数对不上"的历史问题

顺带调了一处排版：窄屏卡片变挤，昵称会被截成“小…”。
所以在宽度小于 560px 时把日期隐藏，把位置让给昵称和三个数字。



### 好友改成双向关注 + 新增粉丝页

以前「好友」页就是「我关注的人」，单向的：我关注了 ta 就算好友，ta 关不关注我完全看不出来。

现在分成两层：

- **好友 = 互相关注**：两个人都关注对方才算
- **粉丝**：关注了我、我还没回关的人，在独立页面里，可以一键「回关」

界面上的变化：

```
好友页头部：  好友 1 · 关注 3                    粉丝 2 ›
好友（互关）： 小光
我关注的 · 等对方回关（2）： 老周   林小满
```

点右上角「粉丝 2 ›」进粉丝页：

```
羽毛   0 篇日记 · 0 粉丝    [回关]      ← 点一下变「互相关注」
小光   5 篇日记 · 2 粉丝    [互相关注]  ← 已经互关的置灰
```

后端：

- `/api/interact/my-follows` 每行多返回 `isMutual`（对方有没有回关），并支持 `?mutual=1` 只看互关
- `/api/interact/my-fans` 补上 `diaryCount` / `fans` / `isFollowedBack`，`total` 改成真实总数
- 新增 `/api/interact/friend-stats`：一次返回 好友数 / 粉丝数 / 我关注数

「我的」页也多了一个「我的粉丝」入口。


### @ 提及、送祝福改走私信（带跳转）

以前这两件事只写进「互动消息」：一句"有人 @ 了你"，看不到是哪条日记、也点不过去；祝福同理。

现在改成**给对方发一条私信**：

```
小海：在日记《这周第四次失眠…》的评论里 @ 了你：@老周 这条你也看看
      [ 查看这条评论 ]        ← 点了直接跳日记详情

小光：给你送了一句祝福：愿你今晚睡个好觉
      [ 去看看 ]              ← 点了直接跳「我收到的祝福」
```

实现上，私信正文里用一个约定：`正文
[跳转] 页面地址`，
前端 `friend-chat` 把 `[跳转]` 后面那截渲染成按钮。这样不用改消息表结构。

互动消息里仍然保留：谁点赞了、谁收藏了、谁评论了、谁回复了你、谁关注了你。


### 红点提醒：把「私信未读」接进来

以前只有两处红点：群聊卡片上的未读数、好友页「互动消息」旁边那个数字。
私信完全没有提示 —— 而这一版把 @ 提及、送祝福都改成了私信，等于这些事"发生了但看不见"。

现在：

- 好友列表每一行右边显示**私信未读条数**（红底白字小圆点）
- 底部「好友」tab 的角标 = 互动消息未读 + 私信未读
- 打开某个人的聊天后（后端会把消息标已读），下一次轮询角标自动减

实测：

```
刚进首页：  好友 tab 角标 7（互动消息 2 + 私信 5），小光那一行显示 5
点进小光的聊天，返回首页：
            角标 2（只剩互动消息），行内未读点消失
```

群聊未读也复核过：往同龄群发一条，小海的首页「同龄群」卡片上出现 3。


### 群聊机器人：被禁言的人求救也要被接住

群里的「🤖」不是管理员，是一条**违规检测 + 危机转接**的自动消息，只有它能说话、没有踢人权限。

分级的处理尺度：

| 情况 | 处理 |
|---|---|
| 第 1 次违规 | 内容不发出 + 温和提醒（不禁言） |
| 第 2 次违规 | 不发出 + 禁言 30 秒 |
| 第 3 次及以后 | 不发出 + 禁言 5 分钟 |
| 10 分钟内不再犯 | 记录清空，重新从第 1 次算 |
| **危机信号**（"撑不下去"之类） | **不处罚**：消息照发，机器人补一条关怀 + 三个免费热线 |

这一版修了一个逻辑顺序问题：原来「禁言检查」在「危机判断」前面，
被禁言的人说“我撑不下去了”会直接返回 429 —— 等于用禁言把求救堵死了。
现在禁言检查里先问一句"这是不是求救"，是求救就放行。

实测：

```
第 1 次违规 → 拦截，禁言 0s
第 2 次违规 → 拦截，禁言 30s
禁言中发"大家好"   → 429 你正在被禁言，还有 29 秒
禁言中发"撑不下去了" → 已发送 + 关怀消息（含 12356 / 010-82951332 / 400-161-9995）
禁言期满再犯 → 第 3 次，禁言 300s
```

机器人自己发的两条消息长这样：

```
🤖 @小海 这句话不太合适，我先不发了。这里不能留联系方式哦
有人说了一句心里话。我不打断你，也不问你为什么。只是想让你知道：
如果这会儿特别难受，这里有免费的电话，随时有人接 ——
全国24小时心理援助热线 12356、北京心理危机研究与干预中心 010-82951332、希望24热线 400-161-9995
```


### 群聊机器人：脏话词库补了一批

实际测试里遇到"你们都是傻逼吧""脑子进屎了"这种，机器人没反应 ——
因为原词表只有"傻子/脑残/贱人"这几个正字，换个同音、换个说法就漏了。

补的口语脏话（按【关键词】列，不是整句，换个语序也拦得住）：

```
傻逼 / 傻B / 煞笔 / 装逼 / 智障 / 脑瘫 / 白痴 / 低能 / 神经病
脑子进水 / 脑子进屎 / 进屎 / 吃屎 / 屎糊 / 一嘴屎 / 满嘴喷粪
狗东西 / 狗屎 / 贱货 / 婊子 / 骚货
操你 / 我操 / 草泥马 / 尼玛 / 他妈的 / 你妈的 / 去你妈
```

刻意没把"逼"单字、"妈的"单字放进去：聊天里"我快被逼疯了""加班到半夜"是正常表达，
误伤比漏判更让人难受。

实测：

```
"你们都是傻逼吧"                → 拦截 · 人身攻击 · 禁言 0s（第一次提醒）
"脑子进屎了"                    → 拦截 · 人身攻击 · 禁言 30s（第二次）
"我快被逼疯了" / "最近压力很大"  → 正常通过
```


### 评论区显示头像（点头像进主页）

评论原来只有"昵称：内容"一行字，人多的时候不容易分清谁是谁。

现在每条评论左边有头像：

- 有上传头像就显示图，没有就用昵称首字（浅蓝圆底）
- **点头像**直接进这个人的主页（`diary-public.html?profileUserId=`）
- 二级回复的头像小一号，缩进保持原样

实测：4 条评论 4 个头像，点第一条跳到 `diary-public.html?profileUserId=4`。


### 私聊也接上了机器人 + 词库扩容

**① 私聊同样过机器人**

以前只有群聊有"🤖 拦截 + 提醒"，私聊虽然也拦，但只返回一句干巴巴的提示。现在：

- 私聊用同一套分级（第 1 次提醒、第 2 次起话更重），只是**不禁言**——私聊是两个人的事，不给第三方权限
- 被拦的句子不发给对方，只在**自己这边**显示一条灰色机器人提示：

```
🤖 这句话不太合适，我先不发了。善语结善缘，换种说法好吗
```

- 危机信号照常发出，并在**自己这边**补一张关怀卡片（热线）；对方看不到这张卡，避免把"你可能不太好受"暴露给聊天对象

**② 求救不受"发得太快"限制**

情绪激动时一句话分几条发很常见，这时候回一句"发得太快了，等 3 秒"是最糟的体验。现在危机信号会跳过频控。

**③ 词库扩容**

新增 40+ 关键词，覆盖：

| 类别 | 新增举例 |
|---|---|
| 人身攻击 | 弱智、蠢猪、猪脑子、去你大爷、sb（拼音缩写） |
| 广告导流 | 代购、微商、扫码、二维码、一手货源、月入过万 |
| 诈骗 | 中奖、验证码、转账、博彩、下注、杀猪盘 |
| 违法 | 代考、枪手、迷药、窃听、洗钱 |
| 色情 | 黄片、裸照、援交、开房 |
| 隐私 | 18 位身份证号 |
| 危机信号 | 轻生、自尽、上吊、跳河、吞药、活不下去 |

**④ 换写法也拦得住**

原来「傻 逼」中间加个空格就漏了：

```
你个傻逼    → 拦 ✅
你个傻 逼   → 拦 ✅（匹配前先抹平空格和零宽字符）
sb / SB     → 拦 ✅（按独立词匹配，absb / subs 不会误伤）
```

实测（私聊连发）：

```
第 1 次 → 这句话不太合适，我先不发了。善语结善缘，换种说法好吗
第 2 次 → 又出现不合适的内容，先安静 30 秒吧。
第 3 次 → 多次出现不合适的内容，先安静 5 分钟。
```


### 私聊也能举报了

举报原来覆盖日记、评论、主页，私聊漏了——而私聊恰恰是最容易收到骚扰的地方。

**怎么用**：在聊天里**长按对方的消息**（手机按住 0.6 秒，电脑按住鼠标左键），弹出理由面板：

```
举报这条私信
举报会提交给管理员，对方不会知道是谁举报的
┌ 广告 / 留联系方式 ┐
│ 诈骗 / 刷单 / 网贷 │
│ 辱骂、人身攻击     │
│ 违法违规内容       │
│ 不适合出现在这个社区│
│ 其他（补充说明）   │
└──────────────────┘
```

自己的消息长按没有反应（后端也会拦），系统提示也不算。

**后端加了校验**，避免“随便传个 id 就能举报”：

```
举报别人的消息           → 成功
重复举报同一条           → 409 你已经举报过了
举报不存在的消息 id      → 404 这条消息不存在
举报自己发的消息         → 400 这是你自己发的消息
举报不在你会话里的消息    → 403 看不到这条消息
```

举报记录照旧进「设置 → 举报记录」。


### 私信不再进「互动消息」+ 举报记录能看详情

**① 私信只亮私信红点**

好友行上已经有未读数、底部角标也把它算进去了，所以「互动消息」里不再重复出现
「XX 给你发了一条私信：…」。现在互动消息只留真正的互动：点赞、收藏、评论、回复、关注。

**② 举报记录点开看详情**

原来只写「举报私信 #217：辱骂攻击」，看的人根本想不起来举报了什么。现在每条都能点开：

```
类型      日记
发布者    小海
内容      今天把拖了很久的那件事做完了。没有想象中那么难…
发布时间  2026-11-04 22:16:19
举报时间  2026-11-04 22:35:31
举报理由  不适合这里
处理状态  处理中
```

四种类型都支持：日记（正文 + 日期）、评论（内容 + 作者）、私信（内容 + 发送者）、用户（昵称 + 签名）。

## 二、AI 聊天说明

`chat.html` 的 AI 陪伴保持**前端直连 DeepSeek**（api.deepseek.com），Key 写在页面里，用于本项目演示。

之后若要换成走服务端（Key 只留 `.env`、对话落库、换设备续聊），
把 `send()` 里的 `fetch(AI_URL, ...)` 换成 `api('/ai/chat', { method: 'POST', body: { message: text } })` 即可，
后端 `/api/ai/chat` 已经就绪。

## 三、怎么验证

1. 打开任意一篇日记 → 右侧操作栏「💬」下面有数字
2. 点「💬」→ 发一条评论 → 数字 +1，评论区里也能看到
3. 回到「发现」→ 对应卡片底部显示 `💬 N  ☆ N  ♡ N`
4. 点一下收藏 → `☆` 变成 `★`，数字 ±1
4. 进别人的主页 → 他的日记卡片同样显示评论数

## 四、和二十三稿的关系

二十四稿 = 二十三稿 + 上面这一处修复。除此之外完全一致，包括：

- 聊天时间分隔（群聊 / 私聊，超过 5 分钟插一条）
- 新账号不再一进来就“十几条未读”
- 登录页没有「先随便看看」入口
- 浏览记录网格（手机 2 列 / 宽屏 3 列）、我的漂流瓶信纸卡片
- 发现页用真实节气照片做配图
- 加好友（扫一扫 / 搜 ID）、加好友问候、头像进主页、举报、二维码、单点登录、创建账号
- 安装相关的健壮性修复（中文路径建表、独立 MySQL 实例、自动补字段等）
