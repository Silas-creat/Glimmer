# 前置安装指南（给前端同学 / 新电脑）

> 目标：在一台**没跑过这个项目**的电脑上，把环境装到位，然后一键安装 + 一键启动能直接跑起来。
> 全程不需要懂后端，照着做即可。遇到报错先看第六节「常见问题」。

---

## 一、先明确：这台电脑需要什么

| 东西 | 需要吗 | 说明 |
|---|---|---|
| **Node.js 18 以上** | ✅ 必须 | 后端和安装脚本都靠它跑。推荐 20 / 22 / 24 |
| **MySQL 8.0** | ✅ 必须 | 数据库。有现成的可以直接用；没有可以另装一个独立实例（脚本会帮你） |
| 项目本身 | ✅ 必须 | 解压后的文件夹（含「一键安装.bat」「一键启动.bat」） |
| 磁盘空间 | ✅ 至少 600 MB | MySQL 222 MB + 依赖 100 MB + 数据若干 |
| 浏览器 | ✅ 推荐 Chrome / Edge | 需要 `getUserMedia`、`fetch` 等现代特性 |
| 联网 | ⚠️ 首次需要 | 装 npm 依赖要联网；装完之后可以离线跑 |

**端口占用一览**（装之前先确认没被别的项目占着）：

| 端口 | 谁用 | 被占的后果 |
|---|---|---|
| 3306 | MySQL（现成的） | 换 3307+ 另装实例即可 |
| 3307 / 3308… | 独立 MySQL 实例 | 脚本会自动往后找 |
| 3000 | 后端 | 被占就换端口，或先关掉占用的程序 |
| 8080 / 8081… | 前端静态服务 | 脚本会自动往后找 |
| 33060 | MySQL X Plugin | **第二个 MySQL 实例最容易撞这里**（新版脚本已处理） |

## 二、第 1 步：装 Node.js

### 2.1 下载

打开 <https://nodejs.org/zh-cn> ，下载 **LTS（长期支持版）** 的 Windows 安装包（`.msi`），一路下一步即可。

> 安装时保持勾选 **"Add to PATH"**（默认就是勾的），否则命令行找不到 `node`。

### 2.2 验证

按 `Win + R`，输入 `cmd`，回车，然后执行：

```bat
node -v
npm -v
```

正常输出类似：

```
v22.11.0
10.9.0
```

**只要版本号 ≥ v18 就行。** 如果提示 `'node' 不是内部或外部命令`：

1. 关掉命令行窗口重新开一个（PATH 要重新加载）
2. 还不行就是安装时没勾 PATH，重新装一次，或手动把 `C:\Program Files\nodejs` 加进环境变量

### 2.3 国内网络慢的话（可选）

```bat
npm config set registry https://registry.npmmirror.com
```

## 三、第 2 步：MySQL —— 先判断你属于哪种情况

一键安装的**第 2 步**会自己检测。你只要提前知道自己是哪种：

| 情况 | 特征 | 你会看到 |
|---|---|---|
| **A. 从没装过 MySQL** | 3306 没人监听 | 脚本会问你装不装 |
| **B. 装过，而且知道 root 密码** | 3306 有监听，密码是你自己设的 | 脚本问你要密码 |
| **C. 装过，但不知道 root 密码** | 3306 有监听（可能是以前别的项目装的） | 脚本提示 `连不上这台机器上已有的 MySQL（不知道 root 密码）` |

### 3.1 情况 A：从没装过

直接跑**一键安装**，脚本会引导你装（需要联网，约 222 MB）。

### 3.2 情况 B：知道密码

一键安装跑到第 2 步时输入密码即可。也可以先自己测一下：

```bat
mysql -h 127.0.0.1 -u root -p
```

输密码能进去就说明密码没问题。

### 3.3 情况 C：不知道密码（最常见）

**不要**去折腾「重置已有 MySQL 的 root 密码」——那会影响这台电脑上别的项目。
直接在脚本里**选 2**：

```
    1) 我知道密码，手动输入
    2) 另装一个独立的 MySQL 实例（端口 3307，密码脚本自己设）   ← 选这个
```

脚本会做这些事（全程不动你已有的 MySQL）：

```
1. 在 D:\mysql\data-3307 建一个新的数据目录（不碰原来的 data）
2. 用 --port 3307 + 独立的 X Plugin 端口启动（避免和 3306 那个抢 33060）
3. 给新实例设一个随机 root 密码
4. 把端口和密码写进 后端源码/.env
5. 建库、建表、灌演示数据
```

> 如果 3307 也被占，脚本会依次试 3308、3309……并在窗口里告诉你最终用了哪个端口。

### 3.4 想自己手动装 MySQL（进阶）

1. 下载 MySQL 8.0 的 **ZIP Archive**（不是 Installer）：<https://dev.mysql.com/downloads/mysql/>
2. 解压到 `D:\mysql\mysql-8.0.28-winx64`（路径别带中文和空格）
3. 初始化数据目录：

```bat
D:\mysql\mysql-8.0.28-winx64\bin\mysqld.exe --initialize-insecure --basedir=D:\mysql\mysql-8.0.28-winx64 --datadir=D:\mysql\data
```

4. 启动（**这个窗口不要关**）：

```bat
D:\mysql\mysql-8.0.28-winx64\bin\mysqld.exe --basedir=D:\mysql\mysql-8.0.28-winx64 --datadir=D:\mysql\data --port=3306 --console
```

5. 另开一个命令行，设密码并改认证方式：

```bat
D:\mysql\mysql-8.0.28-winx64\bin\mysql.exe -h 127.0.0.1 -u root --skip-password
```

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的密码';
FLUSH PRIVILEGES;
```

> `mysql_native_password` 这句别省：mysql2 驱动对 `caching_sha2_password` 支持不稳，设成 native 最省事。

## 四、第 3 步：跑「一键安装」

双击 **一键安装.bat**（普通双击即可，不用管理员）。

**先做一次体检（不改任何东西）**：

```bat
cd 项目文件夹
node setup\install.js --check
```

这个模式只检查：Node 版本、MySQL 能不能连、.env 有没有、依赖装没装，然后告诉你缺什么。

体检通过后，正式安装：

```bat
node setup\install.js
```

它会依次做这些事，每步都有 `✅`：

```
0.  检查 Node            → 版本够不够
1.  检查 MySQL           → 有没有在跑；没有就装
2.  确认数据库账号        → 有现成的用现成的，不知道密码就另装独立实例
3.  建数据库             → CREATE DATABASE IF NOT EXISTS peizhe
4.  生成配置文件          → 写 后端源码/.env（随机密码、随机 JWT 密钥）
5.  装依赖               → npm install（约 100 MB）
5.5 升级表结构           → 老库补字段（session_version / is_sys 等）
6.  灌演示数据           → 主账号 + 演示用户 + 日记 + 四个群 + 祝福 + 漂流瓶
```

看到这个就算成功：

```
==============================================
  🎉 安装完成
==============================================
  下一步：双击「一键启动.bat」
```

> 重新安装是安全的：建库建表都是 `IF NOT EXISTS`，演示数据是幂等的，不会删你的数据。
> 想彻底重来：删掉 `后端源码/.env` 和数据库里的 `peizhe` 库。

## 六、常见问题

### 6.1 「连不上 MySQL，请检查数据库是否启动、.env 里的密码是否正确」

页面能打开但一操作就报这个 → 后端活着、数据库连不上。

```bat
netstat -ano | findstr :3306
type 后端源码\.env | findstr DB_
```

- 端口在听但密码不对 → 重新跑一键安装，或改 `.env` 里的 `DB_PASSWORD`
- 端口没在听 → 手动起 MySQL（见 3.4 第 4 步）
- `.env` 里 `DB_PORT=3307` 但 3307 没起来 → 起 3307 那个实例

### 6.2 装到「另装独立实例」时起不来

新版脚本会打印 MySQL 错误日志尾部。按关键词判断：

| 日志关键词 | 原因 | 处理 |
|---|---|---|
| `33060` / `X Plugin` | 和已有 MySQL 抢 X 端口 | 用最新版脚本（已按端口偏移） |
| `ibdata1 must be writable` | 数据目录被占用 / 权限 | 关掉占用进程；或换 `data-33xx` 目录 |
| `Can't create/write to file` | 路径含中文、或没权限 | 换 `D:\mysql` 这类纯英文路径 |
| `port 3307 already in use` | 端口被占 | 脚本会往后找；也可 `--private-port=3310` |

### 6.3 建表失败：`Failed to open file '...schema.sql', error: 2`

**这是中文路径问题**，不是缺文件。老版脚本用 `mysql` 的 `source` 命令执行 SQL，
路径里带中文或空格（Windows 桌面基本都带）就解析失败。

- 新版脚本已改成「把 SQL 读进内存、走 stdin 喂给 mysql」，中文路径不再受影响
- 如果还报这个，说明拿的是旧包，换成最新版；或者把项目挪到 `D:\weiguang` 这类纯英文路径

### 6.4 「Unknown column 'session_version'」/「is_sys」

老库没升级。跑一次迁移（幂等，可重复）：

```bat
cd 后端源码
node scripts\migrate.js
```

### 6.5 启动时「后端依赖没装」

```bat
cd 后端源码
npm install --omit=dev
```

或者重新跑一键安装。

### 6.6 端口被占（3000 / 8080）

- 3000：关掉占用程序，或改 `.env` 里的 `PORT`
- 8080：不用管，启动脚本会自动往后找（8081、8082…），窗口里会打印实际端口

### 6.7 浏览器打不开摄像头（扫一扫用不了）

摄像头只在**安全上下文**可用：`http://localhost` 可以，`http://192.168.x.x` **不行**（浏览器规则）。

- 本机演示 → 用 `localhost` 打开，扫一扫能直接调摄像头
- 手机通过局域网 IP 访问 → 摄像头被禁，改用扫一扫里的「**选图片识别**」（选一张二维码截图），或「搜 ID 加好友」

### 6.8 双击 .bat 一闪而过

说明脚本里有报错。改成在命令行里跑，能看到报错：

```bat
cd 项目文件夹
node setup\install.js
```

### 6.9 npm install 很慢 / 失败

```bat
npm config set registry https://registry.npmmirror.com
npm cache clean --force
```

然后重新安装。公司网络有代理的话，`npm config set proxy` / `https-proxy` 也要配。

### 6.10 好友列表里同一个人出现两次

现象：好友列表里出现两个「小海」，一个显示「3 篇日记」，一个显示签名。

原因：**库里有两个不同的账号，只是昵称一样**。
注册接口会查重，但演示数据（seed）是直接写库的，不查昵称——
所以「你先注册了一个叫小海的账号」+「再跑一键安装灌演示数据」就会出现两个小海。

处理：跑一次改名脚本（先预览，再加 `--apply` 真改）：

```bat
cd 后端源码
node scripts/fix-duplicate-nick.js
node scripts/fix-duplicate-nick.js --apply
```

规则：同一昵称只保留最早创建的那个，其他改成「昵称·手机后四位」（如 `小海·1509`）。
新版 seed 在灌数据前也会自动处理这种冲突，不会再产生新的重名。

### 6.11 杀毒软件拦截 .bat

部分杀毒会把批处理当可疑脚本。把项目文件夹加进白名单，或直接用命令行跑 `node setup\start.js`。

## 九、还是一步都跑不起来怎么办

按顺序收集这三样发出来，基本能定位：

1. `node -v` 和 `npm -v` 的输出
2. `node setup\install.js --check` 的完整输出
3. `后端源码\.env` 里 `DB_` 开头那几行（**密码可以打码**）

另外看一眼 MySQL 错误日志：`D:\mysql\data\*.err`（或 `data-3307\startup.err`）。
