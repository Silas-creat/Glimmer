# 微光同行 · 接口清单（十四稿）

约定：所有接口返回统一结构

```json
{ "code": 0, "msg": "ok", "data": {} }
```

- `code = 0` 表示成功；非 0 时 `msg` 是给用户看的中文提示
- 需要登录的接口在请求头带 `Authorization: Bearer <token>`
- 空列表统一返回 `{ "list": [], "total": 0 }`，不要返回 `null`

---

## 一、账号（已实现）

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| POST | `/api/auth/register` | `{phone, password, nickname}` | `{token, user}` |
| POST | `/api/auth/login` | `{phone, password}` | `{token, user}` |
| GET | `/api/auth/me` | — | `{user, unreadBless}` |
| PATCH | `/api/auth/me` | `{nickname?, bio?, avatar?}` | `user` |

`user` 结构：`{id, phone, nickname, avatar, bio}`

错误：`400 手机号格式不正确` / `400 密码至少 6 位` / `409 该手机号已注册` / `401 手机号或密码不正确`

## 二、日记（已实现）

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| POST | `/api/diary` | `{content, visibility: private\|public, mood?, day?}` | `diary` |
| GET | `/api/diary/mine?page=1&size=20` | — | `{list, total, page, size}` |
| GET | `/api/diary/public?page=1&size=20` | — | `{list, total, page, size}` |
| GET | `/api/diary/:id` | — | `diary` |
| DELETE | `/api/diary/:id` | — | `{id}` |

`diary` 结构：

```json
{
  "id": 1, "content": "…", "visibility": "public", "mood": "",
  "day": "2026-11-01", "createdAt": "2026-11-01 20:10:00",
  "author": { "id": 3, "nickname": "小海", "avatar": "" }
}
```

规则：
- 一人一天只能写一篇（同一天再写返回 `409`）
- 单篇不超过 2000 字
- **私密日记对非作者一律返回 `404 内容不存在`**（不返回 403，避免暴露“这篇存在”）

## 三、漂流瓶与祝福（已实现）

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| POST | `/api/bottle` | `{content}` | `{id}` |
| POST | `/api/bottle/pick` | — | `bottle` 或 `null`（海面没有新瓶子） |
| GET | `/api/bottle/mine` | — | `{list}` |
| POST | `/api/bottle/:id/bless` | `{content}` | `{id}` |
| GET | `/api/bless/received` | — | `{list}` |
| GET | `/api/bless/sent` | — | `{list}` |
| POST | `/api/bless/:id/read` | — | `{id}` |

`bottle`（捞到的）：`{id, content, createdAt, authorNick, blessed}`
`bless`：`{id, content, bottleId, readAt, createdAt, from:{id,nickname}, to:{id,nickname}}`

规则：同一个瓶子对同一个人只能捞一次；不能给自己扔的瓶子送祝福。

## 四、群聊（待实现，接口先定）

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| GET | `/api/room/list` | — | `{list:[{id,name,intro,memberCount}]}` |
| POST | `/api/room/:id/join` | — | `{ok:true}` |

## 五、AI 对话（待实现，接口先定）

| 方法 | 路径 | 入参 | 返回 |
|---|---|---|---|
| POST | `/api/ai/chat` | `{message, history?}` | `{reply, degraded:false}` |
